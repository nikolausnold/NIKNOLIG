# NIKNOLIG
NIKNOLIG ist eine zukunftsorientierte Technologieplattform, die künstliche Intelligenz, Sicherheit, Gerätevernetzung und digitale Dienste vereint. Mit Elektro-Engel als intelligenter Assistenz verfolgt NIKNOLIG das Ziel, Technologie sicherer, einfacher und für Menschen weltweit zugänglich zu machen.
